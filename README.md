# Open Bot Kit

Little bots with personality, for any app. Each bot is a small SVG character that blinks, breathes, glances around and reacts, and every bot fits in a short share code.

Try it at [forgedaughter.com/bots](https://forgedaughter.com/bots).

## Status

Early. The API is being designed, and the code still lives in [Forge Daughter](https://github.com/fredbergwitz/forge-daughter) until it moves here.
